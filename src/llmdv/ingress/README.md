# ingress

`signals.py` is the one table of what a response reveals about the layers behind it (a build, a backend, recorded evidence, a product's own wording), read the same way at every ingress, plus the `version_headers` a profile declares. `base.py` builds `ServedBy` (which endpoint answered) and the published version signals from it, and the recording client for an ingress. A new product needs no code; a header it sends joins the table once observed on a real response.
