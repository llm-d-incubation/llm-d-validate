# profile

`schema.py` holds the profile dataclasses and the `Disposition` and `SkipClass` vocabularies. `loader.py` turns YAML into them: loading reports every type or shape error at once, and `validate` then reports every other problem, each with its path. `errors.py` holds `ProfileError` and `Diagnostic`, the only two ways the package reports a profile wrong. `compose.py` resolves `extends` and merges each file over its parent before the loader checks the result, and `parse.py` holds the strict value shapes every parser shares. `topology.py` holds the layer graph derived from the ingresses' kinds, and the one rule that decides which layers a report compares. `transport.py`, `fleet.py` and `evolution.py` parse per-ingress HTTP behaviour, fleet invariants and the evolution declarations. Fields are documented in [profiles/REFERENCE.md](../../../profiles/REFERENCE.md).
