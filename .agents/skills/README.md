# Skills

One procedure per task. Each lives at `<name>/SKILL.md`; load the one that matches before you
start. [AGENTS.md](../../AGENTS.md) lists when to use each.

| Skill | For |
| --- | --- |
| [writing-an-infra-profile](writing-an-infra-profile/SKILL.md) | writing or reviewing a profile; splitting one stack into parts; profiles for an llm-d guide's CI lanes; publishing a profile written against a private stack |
| [tracking-llm-d-guide-drift](tracking-llm-d-guide-drift/SKILL.md) | finding what changed in llm-d since the guide profiles' commit: new Tier 3 guides or lanes, removed lanes, changed overlays and router values, and moving the commit |
| [probing-a-fleet-before-asserting](probing-a-fleet-before-asserting/SKILL.md) | writing or changing an assertion about a live response, or a live case fails |
| [writing-a-test-case](writing-a-test-case/SKILL.md) | adding or changing a test case or a test suite: markers, fixtures, proving it can fail, a new suite, the follow-ups |
| [extending-llmdv](extending-llmdv/SKILL.md) | adding a surface, client, assertion or capability, or supporting another gateway, router or engine product |
| [testing-a-model-deployment](testing-a-model-deployment/SKILL.md) | testing a model you were handed endpoints for |
| [running-and-comparing-live-runs](running-and-comparing-live-runs/SKILL.md) | starting (from a PC or as a cluster job), publishing, pulling back and comparing live runs |
| [reporting-a-run](reporting-a-run/SKILL.md) | sharing a run directory; building the annotated HTML dashboard and its notes |
| [triaging-a-run](triaging-a-run/SKILL.md) | finding out what broke in a run and why |
